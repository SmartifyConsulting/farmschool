# FarmerPlus agriculture delivery

The requested entry point is `https://www.farmerplus.earth/farmschool`. The FarmerPlus app displays public agriculture course metadata and opens the FarmerPlus-branded Plusticity portal at `https://forilla.co.za/portal/farmerplus`. Actual learning, payment/access checks, assessments, scoring and verified certificates remain in Plusticity. This is a cross-site training handoff, not single sign-on or an embedded LMS. FarmerPlus app credentials do not automatically grant Plusticity portal membership.

Migration 0080 adds a manager-controlled agriculture-only portal setting. The FarmerPlus portal was created with it enabled, using the existing Georgia Adams administrator as its owner, the FarmerPlus name and its existing earth-green colour. No learner accounts were created and no additional people were enrolled. The logo currently uses the company-name fallback.

Agriculture inventory includes published public agriculture courses plus eligible organization inventory. Other industries, unclassified topics, drafts and another organization's private courses are excluded. The restriction reaches portal Catalogue/My Learning, course branding, checkout/certificate claims through their existing inventory checks, and Programs (a program containing another industry's course is unavailable rather than silently changing its requirements). Historical non-agriculture awards are omitted from the restricted portal's certificate view; underlying original records remain intact.

Agriculture is determined by the existing explicit Agriculture prefix and recognized agricultural topic taxonomy. It is not inferred from course title keywords. Authors/managers must review and classify content correctly before publishing. For example, the current draft category `Other / Bee Business` is not silently treated as agriculture. Private organization courses never appear in the anonymous external catalogue, and the catalogue exposes no lesson bodies, answer keys, learner details or progress. Disabling the portal also disables that catalogue.

The separate FarmerPlus app no longer uses its training page to issue device-only accreditations or display invented fallback lessons when an API fails. Old device records remain stored but are not represented as verified Plusticity awards. Older course links lead to a migration notice or the server-checked Plusticity course entry.

Validation: Plusticity 314 unit tests passed with 17 environment-dependent skips; FarmerPlus 67 unit tests passed. Both apps passed type checking and production builds. The 0080 synthetic SQL fixtures passed before and after installation, as did the existing 0077–0079 portal/certificate/program regressions. The published FarmerPlus portal's anonymous catalogue returned HTTP 200 with zero courses. There were no published trainer-made courses at setup time, so an empty catalogue is intentional. Existing drafts were not published. No Lovable AI builder credits, real payments, email deliveries or AI provider calls were used.

FarmerPlus changes were made in an isolated checkout because its original workspace contains unrelated ledger/costing work. The concurrent remote update was merged without conflicts and the combined app was checked again before pushing. Custom DNS and the farming app's other routes are not part of this change.
