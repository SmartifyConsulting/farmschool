# Customer certificate branding

Plusticity remains the assessment and certificate authority in the application. Company branding changes presentation, not the requirements for an award. Workspace managers can configure a heading, printed signatory name/title and footer. Company name, safe HTTPS logo URL and colour come from workspace branding.

New verified certificates for organization-private courses capture the issuer and wording automatically. For shared courses completed through `/portal/<slug>`, the server also checks the selected published portal, current membership and its course inventory before requesting issuance. The existing certificate transaction continues to verify course version, curriculum, course access, quiz results and practical evidence. Client-side requests cannot select an arbitrary company issuer or write a snapshot.

Issuer snapshots are immutable. Configuration and branding changes affect subsequent awards. Retrying an award or renewing it does not change its original issuer. Existing certificates receive no branding backfill, including an old award first opened or retried through a new portal. The stored logo is a URL; the bytes served at that external URL are not archived or cryptographically sealed. Printed signatory text is not a digital signature.

The portal has a member-only Certificates view, scoped to the learner and customer. Awards retain visibility there when the customer no longer assigns the shared course, provided their original issuer snapshot belongs to that customer and the learner still belongs to the portal. Historical unbranded awards are included only through current organization course/inventory links. General My Learning and the portal use the same certificate display, and printing waits for the saved issuer to load. Public verification includes original issuer wording only when the learner enables sharing. Names, account identifiers and private revocation reasons are not added to the issuer payload; public learner names retain the existing explicit sharing behaviour. The verification page uses a neutral frame around the issuer's certificate.
